# 3D 參孫打獅子(samson3d)

> 真 3D 競技場——士師記十四章五至六節:參孫獨自一人到了亭拿的葡萄園,一隻少壯獅子向他
> 吼叫。耶和華的靈大大感動參孫,他雖然手無器械,卻將獅子撕裂,如同撕裂山羊羔一樣。
> ★兒童安全鐵則:不流血,獅子敗=側躺被制伏,參孫敗=溫柔跪地、溫柔重試。

## 玩法

- **殺獅之戰**:各 100 血,打光獅子血量獲勝。
- **與獅纏鬥**:各 300 血馬拉松,戰滿三百回合以血量判定。
- **練習場**:獅子只走位不攻擊,自由練手感。

WASD 自由走位、Shift 衝刺;**J=輕拳**(快、傷害低)、**K(或空白鍵/點畫面)=重拳**
(慢、傷害高、命中擊退,可長按蓄力放開=**聖靈金光**金色光波,大傷害不血腥);
**C=格擋**(近戰減傷,剛舉起被打=完美格擋);獅子重攻擊(撲咬)出手前會有紅色扇形
預告,快閃開!場上偶爾出現野地的蜂蜜,走近可回血 25%。

## 開發

```bash
npm install && npm run dev
npm run build && npx vite preview --port 4189
node scripts/gen-voice.mjs   # 烤語音(msedge-tts,累加式,已烤過的句子會跳過)
```
